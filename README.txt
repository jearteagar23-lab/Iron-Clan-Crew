IRON CLAN CREW APP — V1.3 CORREGIDA

NOVEDADES
- Opciones de comidas visibles en cada reparto.
- Tres propuestas por comida con alimentos del mercado peruano.
- Cantidades aproximadas en gramos.
- Porcentaje de cada comida y de cada macronutriente.
- Selector intercambiable de proteína, carbohidrato y grasa.
- Cálculo automático de cantidades al cambiar alimentos.
- Nueva caché para evitar que el celular muestre la versión anterior.

SUBIR A GITHUB
1. Descomprime el ZIP.
2. En GitHub entra a Iron-Clan-Crew.
3. Add file > Upload files.
4. Arrastra todos los archivos y reemplaza los existentes.
5. Commit changes.
6. Espera 1–2 minutos y vuelve a abrir Vercel.
7. En el celular, recarga la página; si sigue igual, borra el acceso anterior y abre nuevamente el enlace.
